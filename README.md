# Anime_Tracker
Anime & TV Series Tracker App

A modern React Native application inspired by MyAnimeList that allows users to explore, track, and discover anime & TV series with a clean mobile experience.

The app includes Firebase Authentication, Realtime Database integration, categorized discovery sections, and a tab-based navigation system for smooth user interaction.

Features
User Authentication (Login & Register)
Firebase Realtime Database Integration
Explore Popular Anime & TV Series
Categorized Discovery Sections
Add & Manage Series Data
Responsive UI with React Native
Bottom Tab Navigation
Stack Navigation Support
Persistent User Login using AsyncStorage
Firebase Data Fetching & Submission
